# TikTok Downloader Bot (zip-режим)

Telegram-бот, который скачивает TikTok видео без водяного знака.

- Если в сообщении **1–2 ссылки** — каждое видео отправляется отдельным файлом, пронумерованным (`1.mp4`, `2.mp4`).
- Если ссылок **больше двух** — все видео скачиваются и отправляются **одним zip-архивом** (`videos.zip`), файлы внутри пронумерованы `1.mp4`, `2.mp4`, `3.mp4`...

Никаких кнопок и интерактива — просто кидаешь ссылки, бот отвечает файлами.

## Деплой на Railway

1. Залей этот код в свой GitHub-репозиторий (или форкни/загрузи файлы вручную).
2. На [railway.app](https://railway.app) → **New Project → Deploy from GitHub repo**, выбери репозиторий.
3. Railway сам найдёт `Dockerfile` и соберёт образ.
4. В настройках сервиса → **Variables** добавь переменную:
   ```
   BOT_TOKEN=твой_токен_от_BotFather
   ```
5. Деплой запустится автоматически. В логах должно появиться `Бот запущен...`.

Бот работает через polling (`run_polling`), поэтому никакого публичного URL/webhook настраивать не нужно — достаточно, чтобы сервис был запущен (т.е. деплой "Running" в Railway).

## Локальный запуск

```bash
pip install -r requirements.txt
export BOT_TOKEN="твой_токен"
python bot.py
```

Требуется установленный `ffmpeg` в PATH.

## Использование

Просто отправь боту ссылку (или несколько) на TikTok:

```
https://www.tiktok.com/@user/video/123456789
https://vm.tiktok.com/ABC123/
https://vm.tiktok.com/DEF456/
```

Если ссылок больше двух — придёт `videos.zip` с файлами `1.mp4`, `2.mp4`, `3.mp4`.

## Ограничения

- Лимит размера файла в Telegram-ботах — 50 МБ (на видео и на сам zip-архив). Если архив превышает лимит, бот попросит прислать ссылки меньшими партиями.
